Ma veille techno porte sur PHP

24 Septembre 2026

Nouvelle version de PHP

Le 24 septembre 2026, l'équipe PHP a publié PHP 8.6.0 RC2 (Release Candidate 2). Il s'agit d'une version presque finalisée qui permet aux développeurs de tester les nouvelles fonctionnalités et de détecter d'éventuels problèmes avant la sortie officielle. La version stable de PHP 8.6 est prévue pour le 19 novembre 2026. Cette version de test ne doit donc pas encore être utilisée pour des applications en production.

Détails →

Quelques nouveautés

PHP 8.6 apporte plusieurs évolutions intéressantes : Application partielle de fonctions : permet de simplifier l'utilisation de certaines fonctions avec des paramètres déjà définis. Fonction clamp() : permet de maintenir facilement une valeur entre une limite minimale et une limite maximale. Classe Time\Duration : facilite la gestion et le calcul des durées. Améliorations de sécurité : certains paramètres liés aux sessions PHP sont renforcés par défaut.

Intérêt pour les développeurs

Cette nouvelle version permet aux développeurs de découvrir les futures fonctionnalités de PHP, de tester la compatibilité de leurs applications et de préparer leur passage vers PHP 8.6.

8 Octobre 2026

PHP 8.6.0 RC3 disponible pour les tests

Le 8 octobre 2026, l'équipe PHP a annoncé la disponibilité de PHP 8.6.0 RC3 (Release Candidate 3). Cette nouvelle version de test poursuit le développement de PHP 8.6 avant sa sortie officielle. Elle permet aux développeurs de tester les fonctionnalités prévues et de signaler les éventuels bugs. La prochaine version candidate, RC4, est prévue pour le 22 octobre 2026. Cette version ne doit pas être utilisée sur des applications en production.

Détails →

Quelques nouveautés

Cette version candidate poursuit les tests des fonctionnalités de PHP 8.6. Les développeurs peuvent vérifier le comportement des nouvelles fonctionnalités, tester la compatibilité avec leurs projets existants et signaler les problèmes rencontrés. L'équipe PHP peut ainsi corriger les erreurs avant la publication de la version stable.

Intérêt pour les développeurs

Cette version permet aux développeurs de découvrir les évolutions à venir de PHP et de commencer à préparer leurs applications à la prochaine mise à jour. Les tests permettent également de contribuer à l'amélioration de la stabilité du langage.

21 Octobre 2026

Mise à jour de sécurité importante pour PHP

Le 21 octobre 2026, l'équipe PHP a publié plusieurs mises à jour de sécurité, notamment PHP 8.5.12, 8.4.27, 8.3.36 et 8.2.35. Ces versions corrigent deux vulnérabilités critiques pouvant permettre l'exécution de code à distance sans authentification. L'équipe PHP recommande fortement aux utilisateurs de mettre à jour leurs installations afin de protéger leurs applications.

Détails →

Quelques nouveautés

Ces mises à jour corrigent deux failles de sécurité critiques identifiées sous les références CVE-2026-109618 et CVE-2026-109619. Ces vulnérabilités peuvent permettre à une personne malveillante d'exécuter du code à distance sans authentification dans certaines configurations. Les nouvelles versions intègrent les correctifs nécessaires pour protéger les installations PHP.

Intérêt pour les développeurs

Cette mise à jour rappelle l'importance de maintenir régulièrement son environnement de développement à jour. Les développeurs doivent vérifier les versions de PHP utilisées par leurs applications et installer les correctifs de sécurité afin de limiter les risques de cyberattaques.
