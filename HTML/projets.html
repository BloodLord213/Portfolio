Site web pour la filière informatique du lycée Saint-Denis

HTML CSS PHP MySQL GitHub

Contexte

Projet réalisé en équipe de trois dans le cadre de ma première année de BTS. L'objectif était de développer un site web dédié à la présentation de la filière informatique du lycée Saint-Denis (BTS et Licence).

Objectifs

  • Centraliser les informations importantes de la filière informatique.
  • Présenter les formations proposées (BTS et Licence).
  • Faire découvrir les cours, les activités et les projets réalisables.
  • Présenter les débouchés professionnels et les compétences acquises.
  • Créer un site vitrine permettant aux futurs étudiants de mieux connaître la filière.

Développement du projet

  1. Première version : création d'un site statique en HTML et CSS.
  2. Deuxième version : intégration de PHP pour rendre le site dynamique.
  3. Mise en place d'une base de données MySQL pour stocker et gérer les informations.
  4. Travail collaboratif à trois avec GitHub pour le partage et le suivi du code.

Difficultés rencontrées

Le passage d'un site statique à un site dynamique a nécessité de comprendre le fonctionnement de PHP et les interactions avec une base de données MySQL. Le travail en équipe a également demandé une bonne organisation et une coordination régulière à l'aide de GitHub.

Bilan & apprentissages

Ce projet m'a permis de découvrir et de mettre en pratique le développement web, en passant de la création d'une interface statique à un site dynamique utilisant PHP et MySQL. J'ai également développé mes compétences en travail collaboratif, en gestion de versions avec GitHub et en organisation de projet informatique.
