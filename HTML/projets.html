Application de gestion de bibliothèque

PHP MySQL Bootstrap

Contexte

Projet réalisé dans le cadre du module B3 (Conception et développement). L'objectif était de simuler une commande client réelle en suivant les phases d'analyse, de conception et de développement.

Objectifs

  • Gérer les livres, les adhérents et les emprunts
  • Authentification sécurisée pour l'administrateur
  • Interface d'administration complète avec tableau de bord
  • Génération de rapports d'emprunts en retard

Fonctionnalités développées

  1. CRUD complet sur les livres et adhérents
  2. Système d'emprunt avec calcul automatique des dates de retour
  3. Alertes de retard par email (simulation)
  4. Moteur de recherche par titre, auteur ou ISBN
  5. Pagination et tri des résultats

Difficultés rencontrées

La gestion des relations entre les tables a nécessité une modélisation rigoureuse avec des clés étrangères. La sécurisation des formulaires contre les injections SQL a également demandé une attention particulière.

Bilan & apprentissages

Ce projet m'a permis de consolider mes compétences en PHP procédural et en modélisation de base de données relationnelle. J'ai appris à structurer un projet web de A à Z, du MCD jusqu'au déploiement local.

Site e-commerce – boutique en ligne

React Node.js MongoDB

Contexte

Projet personnel lancé pour approfondir React et découvrir le développement full-stack JavaScript. Inspiré d'une boutique de vêtements fictive.

Objectifs

  • Apprendre React et les hooks
  • Découvrir une API REST avec Node.js/Express
  • Manipuler MongoDB comme base NoSQL
  • Mettre en place un système d'authentification JWT

Fonctionnalités développées

  1. Catalogue produits avec filtres et recherche
  2. Panier d'achat avec gestion des quantités
  3. Tunnel de commande (adresse, paiement simulé)
  4. Espace compte utilisateur
  5. Back-office administrateur (gestion stocks et commandes)

Difficultés rencontrées

La gestion de l'état global du panier m'a conduit à découvrir le Context API de React. La mise en place de l'authentification JWT entre le front et le back a été la partie la plus complexe.

Bilan & apprentissages

Ce projet personnel m'a fait progresser très rapidement sur React et sur l'architecture client/serveur. Encore en cours, il me sert de terrain d'expérimentation pour chaque nouvelle technologie que j'apprends.

Application de gestion RH

Symfony MySQL Twig

Contexte

Projet de groupe (3 étudiants) réalisé en méthode Agile (Scrum) sur 6 semaines. Chaque sprint de 2 semaines donnait lieu à une démo client avec le professeur jouant le rôle du product owner.

Objectifs

  • Développer une application métier avec Symfony
  • Travailler en équipe avec Git/GitLab
  • Appliquer la méthode Agile Scrum
  • Respecter un cahier des charges fonctionnel

Fonctionnalités développées

  1. Gestion des employés (CRUD)
  2. Demandes de congés avec workflow de validation
  3. Suivi des absences et heures supplémentaires
  4. Génération de fiches de paie en PDF
  5. Tableau de bord RH avec statistiques

Difficultés rencontrées

La coordination en équipe sur un même dépôt Git a généré des conflits de fusion. Nous avons mis en place des branches par feature et des pull requests pour mieux organiser le travail collectif.

Bilan & apprentissages

Ce projet m'a appris à travailler en équipe de développement, à utiliser Symfony avec son système de bundles, et à appliquer Agile dans un vrai contexte de projet.

Jeu Quizz multijoueur

JavaScript Socket.io Express

Contexte

Projet réalisé en autonomie pour découvrir les WebSockets et la programmation événementielle côté serveur. Inspiré de Kahoot.

Objectifs

  • Comprendre le fonctionnement des WebSockets
  • Gérer des salles de jeu simultanées côté serveur
  • Créer une interface réactive en JavaScript vanilla
  • Gérer les timers et la synchronisation en temps réel

Fonctionnalités développées

  1. Création et rejointe de salles avec code unique
  2. Questions à choix multiples avec timer 20 secondes
  3. Classement mis à jour en direct après chaque question
  4. Mode hôte pour lancer les parties et choisir les quiz
  5. Banque de questions personnalisable

Difficultés rencontrées

La synchronisation des timers entre plusieurs clients connectés a été le défi principal. La gestion des déconnexions inattendues a nécessité des mécanismes de nettoyage côté serveur.

Bilan & apprentissages

Ce projet m'a révélé la puissance des WebSockets pour les applications temps réel. J'ai mieux compris l'architecture événementielle et la gestion d'état côté serveur Node.js.

Dashboard de monitoring réseau

Python Flask Chart.js

Contexte

Projet transversal entre le module réseau et le module développement. L'objectif était de créer un outil de monitoring simple pour surveiller un parc de machines virtuelles.

Objectifs

  • Interroger des équipements réseau via SNMP/ping
  • Exposer les données via une API Flask
  • Afficher des graphiques en temps réel avec Chart.js
  • Générer des alertes en cas de panne

Fonctionnalités développées

  1. Ping automatique de toutes les machines toutes les 30 secondes
  2. Graphiques de disponibilité et de latence
  3. Historique des incidents sur 7 jours
  4. Système d'alertes avec horodatage
  5. Export des logs en CSV

Difficultés rencontrées

L'interrogation SNMP en Python a demandé l'utilisation de la librairie pysnmp, peu documentée. La mise en place du polling asynchrone sans bloquer le serveur Flask a nécessité l'utilisation de threads.

Bilan & apprentissages

Ce projet m'a ouvert à Python pour le développement back-end et aux notions de supervision réseau. La combinaison d'un backend léger et d'une interface dynamique s'est révélée très efficace.
